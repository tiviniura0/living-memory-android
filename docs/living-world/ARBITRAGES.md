# Arbitrages et limites
- DTO : valeurs JSON immuables avec accès typés et codec strict, sans génération de classes. Si l'ergonomie est insuffisante en L2, ajouter des constructeurs typés sans changer le format.
- Publication : le push Git CLI n'était pas authentifié. Les commits distants sont publiés par l'API GitHub avec vérification du SHA de tête ; le premier agrège T1–T6, les commits locaux conservent les étapes. Les SHA locaux et distants diffèrent ; seul le SHA distant de l'artefact est la référence installable.
- Ordre : CLI et tests purs de boucle ont avancé pendant l'attente de CI Flutter, après leurs dépendances T1–T6. Le journal chronologique n'est donc pas strictement numérique.
- Matériel : durabilité Android réelle, gestes et rendu accessible, consommation S22 non certifiés. Les recettes sont fournies ; des défauts propres au téléphone peuvent subsister.
- Manifeste corrompu : refus explicite avec conservation des fichiers. Les checkpoints orphelins ne sont pas activés ; une récupération manuelle peut être nécessaire.
- Mineur différé de la revue : la fabrique peut refuser certaines très grandes populations à cause du placement sur obstacle (1000 reproduit). Les cinq habitants initiaux sont vérifiés ; les plafonds élevés ne sont pas des capacités validées.
