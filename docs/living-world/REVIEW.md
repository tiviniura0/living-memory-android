# Revue indépendante L1
Une revue distincte a examiné le diff complet depuis 376ccf33353ec101b1c424b6121eb69ecfc55f62. Aucun défaut critique ; quatre défauts importants ont été identifiés : référence d'action appartenant à un autre agent dans un import, absence de relèvement explicite du plafond dans l'UI, export silencieux d'une ancienne génération après échec de sauvegarde, concurrence import/sauvegarde de lifecycle.
Correction : validation propriétaire/action ; session hôte Dart testable qui sérialise capture, sauvegarde, import et activation ; export annulé en cas d'écriture impossible ; confirmation explicite de plafond dans le dialogue d'import. Les quatre régressions ont été reproduites avant correction, puis vérifiées par les tests de contrats/session. La couche Flutter délègue à la session testée.
Mineur différé : la fabrique peut refuser certaines très grandes populations parce que son placement initial rencontre les obstacles générés (reproduction à 1000 habitants). Le démarrage à cinq habitants n'est pas affecté. Ne pas présenter 1000 habitants comme une capacité validée ; benchmark et placement à étendre avant utilisation de ces profils.
Points non jugés matériellement par la revue : durabilité réelle Android lors d'une coupure, gestes réels et accessibilité, performances S22 et provenance finale APK/CI. Ils restent dans la recette matérielle. Le manifeste corrompu provoque un refus explicite avec conservation des fichiers ; une récupération plus avancée exigerait un historique de manifestes validés, hors de cette version.
Aucune fusion effectuée. Les essais matériels et la clé de distribution durable restent des étapes distinctes.
